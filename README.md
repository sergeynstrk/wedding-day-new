# Приглашение Сергея и Юли

Запуск из каталога проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

- Просмотр: http://localhost:8000/
- Расстановка декора: http://localhost:8000/?edit=1

В редакторе перетаскивайте предметы мышью или пальцем. Для выбранного предмета доступны размер и поворот. Стрелки двигают его на 1 px, Shift + стрелка — на 10 px. Кнопка «Отменить» отменяет последнее действие, «Вернуть предмет» сбрасывает выбранный предмет, «Сбросить экран» — текущую расстановку.

Позиции автоматически сохраняются в localStorage этого браузера отдельно для ширин до 780 px, 781–1399 px и от 1400 px. Обычный просмотр в том же браузере использует сохранённую расстановку. Кнопка «Скачать расстановку» экспортирует JSON, который можно передать для внесения координат в исходный сайт. Сам редактор файлы проекта не изменяет.
