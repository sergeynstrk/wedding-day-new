# Изображения из папки reference

Выбраны из предоставленной пользователем сохранённой страницы `reference/Сайтмейкер_files`.

- `dress-burgundy.webp` — women-02.webp, пример бордового платья.
- `suit-burgundy.webp` — men-03.webp, пример бордового костюма.
- `chapel.svg`, `rings.svg`, `dinner.svg`, `car.svg` — соответствующие icon-*.svg, иллюстрации этапов дня.

Это примеры одежды, а не фотографии молодожёнов. Исходная папка не изменялась. Скрипты и код сохранённой страницы не подключены.
